# Web back end 18

## 1. Cập nhật Hyperlink

Trong file index.hbs, sửa đường dẫn:
```
<a href="index.html">Home</a>
```

➡️ Thành:
```
<a href="/">Home</a>
```

👉 Khi click, trình duyệt gửi request tới route /

## 2. Tạo giao diện các trang con

### Bước 1: Di chuyển file

Chuyển các file từ thư mục public sang views:

cart.html → views/cart.hbs
checkout.html → views/checkout.hbs
contact.html → views/contact.hbs
login.html → views/login.hbs
my-account.html → views/my-account.hbs
product-detail.html → views/product-detail.hbs
product-list.html → views/product-list.hbs
wishlist.html → views/wishlist.hbs

### Bước 2: Đổi đuôi file

.html → .hbs

### Bước 3: Xóa header & footer

Trong mỗi file .hbs:

- Xóa phần header

- Xóa phần footer

👉 Vì đã dùng layout main.hbs

## 4. Cấu hình route trong index.js
```
// trang chủ
app.get('/', (req, res) => {
    res.render('index');
});

// các trang con
app.get('/:page', (req, res) => {
    res.render(req.params.page);
});
```

👉 Ví dụ:

/cart → render cart.hbs

/contact → render contact.hbs

## 5. Sử dụng Partial

### 5.1 Tạo sidebar

Tạo file:

views/partials/sidebar.hbs

Trong product-list.hbs:
```
{{> sidebar }}
```

### 5.2 Tạo product-item

Tạo file:

views/partials/product-item.hbs

Trong product-list.hbs:
```
{{> product-item }}
```
