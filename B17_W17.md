# Web back end 17

## 1. Server-side template engine

### Khái niệm
- Là công cụ tạo **HTML động ở phía server**
- Kết hợp:
  - Template (HTML + placeholder)
  - Data (dữ liệu từ server)
→ Render ra HTML hoàn chỉnh gửi về client

### Ví dụ:
- Template:
```html
<h1>Hello {{name}}</h1>
```

Ưu điểm:

- Tạo giao diện động

- Tách biệt logic & giao diện

- SEO tốt

- Load nhanh lần đầu

Nhược điểm:

- Không phù hợp SPA (ít tương tác động)

- Phải reload khi thay đổi nội dung

## 2. Express-handlebars

Khái niệm

Là server-side template engine

Dùng trong Express để tạo HTML động

Sử dụng cú pháp:

- {{variable}}

- {{#each}}

- {{#if}}

## 3. Cài đặt
```
pnpm i -s express-handlebars
```

package.json:
```js
"dependencies": {
  "express": "^4.21.2",
  "express-handlebars": "^8.0.1"
}
```

## 4. Cấu trúc thư mục
```css
TeoShop/
├── views/
│   ├── layouts/
│   │   └── main.hbs
│   ├── partials/
│   │   ├── header.hbs
│   │   └── footer.hbs
│   ├── index.hbs
│   └── cart.hbs
└── index.js
```

Ý nghĩa:

- views/: chứa template

- layouts/: layout chính

- partials/: thành phần tái sử dụng

- *.hbs: file giao diện

## 5. Cấu hình Express-handlebars
```js
const express = require('express');
const app = express();
const expressHandlebars = require('express-handlebars');

app.use(express.static(__dirname + "/public"));

app.engine('hbs', expressHandlebars.engine({
    layoutsDir: __dirname + '/views/layouts',
    partialsDir: __dirname + '/views/partials',
    extname: 'hbs',
    defaultLayout: 'main'
}));

app.set('view engine', 'hbs');
```

6. Layout (main.hbs)
Vai trò:

Là khung chung (header + footer)
```html
<!-- Header -->

{{{ body }}}

<!-- Footer -->
```

{{{ body }}}: nơi chèn nội dung trang con

## 7. Render trang
```js
app.get('/', (req, res) => {
    res.render('index');
});
```

→ index.hbs sẽ được chèn vào {{{ body }}} của main.hbs

## 8. Lưu ý quan trọng

Xóa index.html trong public

Phải cấu hình static:
```js
app.use(express.static(__dirname + "/public"));
```

→ để load CSS, JS, hình ảnh

## 9. Luồng hoạt động

- Client gửi request /

- Express nhận request

- Gọi res.render('index')

- Engine:

  - Load main.hbs

  - Chèn index.hbs vào {{{ body }}}

- Trả HTML hoàn chỉnh về client

## 10. Ghi nhớ nhanh

Template engine = HTML + data

Express-handlebars = SSR trong Express

main.hbs = layout

{{{ body }}} = vùng nội dung

res.render() = render view
