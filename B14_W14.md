# Web back end 14

## 14. Lập trình hướng sự kiện

---

## 14.1 Lập trình hướng sự kiện (Event-driven)

### 🔹 Khái niệm

Lập trình hướng sự kiện là mô hình mà chương trình:
- **Không chạy tuần tự từ trên xuống**
- Mà **chờ sự kiện xảy ra** rồi xử lý

---

### 🔹 Các loại sự kiện

- Người dùng: click, nhập liệu
- Hệ thống: đọc file, timeout
- Mạng: request từ client

---

### 🔹 Nguyên lý

- Đăng ký sự kiện
- Chờ sự kiện xảy ra
- Gọi hàm xử lý (callback)

---

## 14.2 Event-driven trong Node.js

### 🔹 Đặc điểm

- Node.js dùng mô hình **event-driven**
- Phù hợp ứng dụng:
  - Web
  - API
  - I/O (file, database, network)

---

### 🔹 I/O là gì

- Input/Output (đọc/ghi dữ liệu)
- Ví dụ:
  - Đọc file
  - Gọi API
  - Query database

---

### 🔹 Thành phần chính

#### 1. Event
- Là sự kiện xảy ra
- Ví dụ:
  - HTTP request
  - Timeout
  - Lỗi

---

#### 2. EventEmitter
- Quản lý sự kiện

```js
on(event, handler)
emit(event, data)
```

#### 3. Event Loop

Vòng lặp kiểm tra sự kiện

Thực thi callback khi có event

#### 4. Event Handler

Hàm xử lý khi event xảy ra

## 14.3 Thực hành

### 🔹 Cách 1: Hàm thường
```js
'use strict'

const express = require('express')
const app = express();
const port = process.env.PORT || 9000

const events = require('events');
const eventEmitter = new events.EventEmitter();

eventEmitter.on('hetGio', xuLyThongBao);

function xuLyThongBao(tb) {
    console.log(tb);
}

setTimeout(() => {
    eventEmitter.emit('hetGio', 'Hết giờ học rồi, về thôi!!!!!!!');
}, 2000);

app.listen(port, () => {
    console.log(`server dang chay tren cong ${port}`);
});
```

### 🔹 Cách 2: Arrow function
```js
'use strict'

const express = require('express')
const app = express();
const port = process.env.PORT || 9000

const events = require('events');
const eventEmitter = new events.EventEmitter();

    console.log(tb);
});

    eventEmitter.emit('hetGio', 'Hết giờ học rồi, về thôi!!!!!!!');
}, 2000);

app.listen(port, () => {
    console.log(`server dang chay tren cong ${port}`);
});
```

# 14.4 Bài tập

## Bài tập 14.2 Sử dụng module events của Nodejs để lập trình hướng sự kiện. Viết một chương trình đơn giản như sau:

- Khai báo sự kiện vaoLop (vào lớp), với hàm xử lý đi kèm là xuLyVaoLop

- Sử dụng hàm setTimeOut() để hẹn giờ vào lớp là 5 giây

- Hết 5 giây, web server sẽ thông báo “Đã đến giờ học” tới cửa sổ console của web server

- Viết bằng 2 cách: hàm thông thường và hàm mũi tên.

### ✔ Cách 1: Hàm thường
```js
const events = require('events');
const eventEmitter = new events.EventEmitter();

eventEmitter.on('vaoLop', xuLyVaoLop);

function xuLyVaoLop() {
    console.log("Đã đến giờ học");
}

setTimeout(() => {
    eventEmitter.emit('vaoLop');
}, 5000);
```

### ✔ Cách 2: Arrow function
```js
const events = require('events');
const eventEmitter = new events.EventEmitter();

eventEmitter.on('vaoLop', () => {
    console.log("Đã đến giờ học");
});

setTimeout(() => {
    eventEmitter.emit('vaoLop');
}, 5000);
```

Câu hỏi 14.3 Mô hình lập trình hướng sự kiện trong Node.js là gì? Phát biểu nào sau đây không đúng?

(A.) Event Emitter liên tục kiểm tra hàng đợi sự kiện và thực thi các hàm callback khi có sự kiện xảy ra.

B. Event là các hành động hoặc sự thay đổi trạng thái xảy ra trong ứng dụng.

C. Event Loop liên tục kiểm tra hàng đợi sự kiện và thực thi các hàm callback khi có sự kiện xảy ra.

D. Event Handler là các hàm được gọi khi một sự kiện xảy ra.
