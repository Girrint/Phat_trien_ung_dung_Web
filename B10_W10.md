## 10. Hàm callback

**callback**.

---

## 10.1 Hàm callback là gì

### 🔹 Khái niệm

Hàm callback là một hàm được **truyền vào hàm khác như một tham số**, và sẽ được gọi sau khi hàm "cha" hoàn thành.

👉 Callback = "gọi lại"

---

### 🔹 Đặc điểm

- Truyền như tham số
- Thực thi bất đồng bộ
- Linh hoạt (có thể là function thường, arrow function, anonymous)
- Có thể gây **callback hell**

---

### 🔹 Tình huống sử dụng

- Xử lý sự kiện (click, submit,...)
- Gọi API
- setTimeout, setInterval
- Xử lý mảng (forEach, map, filter, reduce)
- Tùy chỉnh logic

---

## 🔹 Ví dụ

### Ví dụ 1: Xử lý sự kiện

```html
<button id="dang-ky">Đăng ký</button>

<script>
document.getElementById("dang-ky").addEventListener("click", () => {
    alert("Nút đã được bấm!");
});
</script>
```

Ví dụ 2: setTimeout
```js
setTimeout(() => {
    console.log("Đã hết 5 giây!");
}, 5000);

console.log("Đang chờ");
```

Ví dụ 3: Duyệt mảng
```js
const numbers = [1, 2, 3, 4];
numbers.forEach(num => console.log(num * num));
```

Ví dụ 4: Gọi API
```js
function getUser(userId, callback) {
    fetch(`https://jsonplaceholder.typicode.com/users/${userId}`)
        .then(res => res.json())
        .then(data => callback(null, data))
        .catch(err => callback(err, null));
}

getUser(1, function(error, user) {
    if (error) {
        console.error(error);
    } else {
        console.log(user.name);
    }
});
```

Ví dụ 5: Callback tùy chỉnh logic
```js
function xuLyMang(arr, callback) {
    for (let i = 0; i < arr.length; i++) {
        arr[i] = callback(arr[i]);
    }
    return arr;
}

const numbers = [1, 2, 3];

console.log(xuLyMang(numbers, x => x * x)); // [1,4,9]
console.log(xuLyMang(numbers, x => x * 2)); // [2,8,18]
```

Ví dụ 6: Callback hell
```js
setTimeout(() => {
    console.log("Bước 1");

    setTimeout(() => {
        console.log("Bước 2");

        setTimeout(() => {
            console.log("Bước 3");
        }, 1000);

    }, 1000);

}, 1000);
```

### 🔻 Nhược điểm

Callback hell (lồng nhiều callback)

Khó xử lý lỗi

Khó đọc với chương trình lớn

👉 Giải pháp: dùng Promise hoặc Async/Await

## 10.2 Callback trong index.js (Express)

### 🔹 Code

```js
'use strict' //Bật chế độ strict → giúp code an toàn hơn

const express = require('express') //Import thư viện Express
const app = express(); //Tạo app server

const port = process.env.PORT || 9000 //Dùng port môi trường hoặc mặc định 9000

app.get("/", (req, res) => {
    res.send('Chao ban den voi TeoShop!');
});

app.listen(port, () => {
    console.log(`server dang chay tren cong ${port}`);
});
```

### app.get()
```js
app.get("/", (req, res) => {
    res.send('Chao ban den voi TeoShop!');
});
```

- Xử lý request GET "/"

- Callback (req, res) => {}

- req: request

- res: response

### app.listen()
```js
app.listen(port, () => {
    console.log(`server dang chay tren cong ${port}`);
});
```

- Khởi động server

- Callback chạy khi server start

### 🔹 Lưu ý

app.listen() chạy xong trước

app.get() chờ request → chạy sau
